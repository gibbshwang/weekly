# MVP IA / 스크린맵 — MOODEX v0.1

**작성일**: 2026-03-23
**스코프**: 1주 MVP (Next.js App Router 기준)

---

## 라우트 구조

```
/                       → 홈 리다이렉트 → /dashboard
/dashboard              → 메인 대시보드 (핵심 화면)
/history                → 히스토리 차트 (30일 무료 / 90일+ 유료)
/guide                  → 실전 대응 가이드
/subscribe              → Pro 구독 페이지
/subscribe/success      → 구독 완료 확인
/api/score              → MOODEX Score API (서버사이드)
/api/history            → 히스토리 데이터 API
/api/subscribe          → 이메일 구독 등록 API
```

## 모바일 반응형 결정

- 기준 너비: 375px (iPhone SE)
- 자산 카드: 모바일 2열 그리드, 태블릿+ 4열
- 차트: 모바일 전체 너비, 세로 높이 200px
- 헤더: 모바일 로고 + Pro 버튼만, sticky
- 대응 가이드: 모바일에서 탭 전환 (아코디언 대신)
