# PRD ONE-PAGER — Fear & Greed Contrarian Opportunity Dashboard

**작성일**: 2026-03-25  
**스코프**: v1 리디자인 / 분석형 MVP

---

## 1. 문제 정의

기존 Fear & Greed UI는 현재 점수와 공포/탐욕 라벨만 보여주는 경우가 많다.  
하지만 사용자가 실제로 궁금한 것은 **지금이 어떤 행동 구간인지**, 그리고 **과거 유사 사례에서는 이후 자산 가격이 어떻게 움직였는지**다.

사용자는 단순한 심리 표시가 아니라 아래 질문에 답을 원한다:
- 지금이 역발상 관점에서 매수 후보 구간인가?
- 지금이 과열/탐욕 구간이라면 과거에는 이후 얼마나 조정이 왔는가?
- 주식, 원자재, 코인 중 어떤 자산이 이런 구간에 더 잘 반응했는가?

즉 문제는 “현재 심리 상태를 보여주는 것”이 아니라, **심리 지표를 과거 사례 기반의 행동 보조 도구로 바꾸는 것**이다.

---

## 2. 제품 비전

Fear & Greed 지표를 단순 시황 위젯이 아니라,  
**극단적 공포/탐욕 구간에서 과거 유사 사례 이후 자산별 가격 반응을 비교해 보여주는 역발상 투자 인사이트 대시보드**로 재정의한다.

핵심은 다음 3가지를 한 화면에서 연결하는 것이다:
1. **현재 시장 심리 상태**
2. **과거 유사 구간의 이후 성과**
3. **매수/매도 관점의 양방향 해석**

---

## 3. 타겟 사용자

| 사용자 유형 | 설명 |
|------------|------|
| **Primary** | 미국 증시/코인/원자재 시장을 함께 보는 개인 투자자 |
| **Secondary** | 시장 데이터 기반 콘텐츠를 만드는 크리에이터, 매크로/심리 지표에 관심 있는 사용자 |
| **Not target** | 초고빈도 트레이더, 기관용 정밀 퀀트 툴 사용층 |

---

## 4. 핵심 가치 제안

1. **지금 시장이 공포/탐욕 중 어디에 있는지 즉시 이해**할 수 있다.
2. **과거 유사 구간 이후 자산별 반응**을 비교해볼 수 있다.
3. 사용자는 단순 지표 소비가 아니라 **역발상 관점의 행동 보조 인사이트**를 얻는다.

---

## 5. 핵심 제품 아이디어

### A. 공포 구간 = 역발상 매수 분석
- Fear & Greed가 특정 기준 이하일 때를 매수 후보 구간으로 정의
- 과거 유사 사례 이후 7D / 30D / 90D / 180D 자산 수익률 분석
- 평균, 중앙값, 승률, 최대 추가 하락까지 함께 표시

### B. 탐욕 구간 = 역발상 매도 분석
- Fear & Greed가 특정 기준 이상일 때를 매도 후보 구간으로 정의
- 과거 유사 사례 이후 주식, 원자재, 코인 등의 조정/하락 패턴 분석
- 평균, 중앙값, 음의 수익률 확률, 최대 낙폭 표시

### C. 현재와 유사한 과거 사례 제시
- 현재 수치와 가장 비슷한 과거 사례 3개 제공
- 당시 점수, 날짜, 이후 자산 성과 요약 제공

## 6. MVP 핵심 기능 (In Scope)

- [x] 현재 Fear & Greed 점수 + regime label + contrarian summary
- [x] Buy Timing Analysis (낮은 점수 구간 이후 반등 분석)
- [x] Sell Timing Analysis (높은 점수 구간 이후 조정 분석)
- [x] Cross-Asset Comparison Heatmap
- [x] Historical Analog Cases Top 3
- [x] Methodology / Disclaimer 섹션
- [x] Threshold 조정 UI (예: <=25, >=75)

---

## 8. 핵심 UX 구조

1. **Hero Summary**
   - 현재 점수
   - 현재 레짐
   - 유사 사례 수
   - 핵심 forward return 요약

2. **Buy Timing vs Sell Timing**
   - 공포 구간 분석
   - 탐욕 구간 분석
   - 동일 위계에서 비교 가능하게 배치

3. **Cross-Asset Heatmap**
   - 주식 / 코인 / 원자재 자산군 비교
   - 7D / 30D / 90D / 180D 기준 성과 표시

4. **Historical Analog Cases**
   - 현재와 가장 유사한 과거 사례 3개

5. **Methodology / Disclaimer**
   - 표본 수, 기간, 계산 기준, 해석 한계 노출

---

## 9. 핵심 데이터 표시 원칙

- 평균만 보여주지 말고 **중앙값, 승률, 표본 수**를 함께 제공
- 가능하면 **최대 낙폭 / 최대 추가 하락**도 같이 제공
- “지금 사라/팔아라” 식의 단정 대신
  - “Historically…”
  - “In similar past regimes…”
  같은 해석형 문구 사용
- 사용자가 신뢰할 수 있도록 **방법론과 제한사항**을 명시

## 10. 성공 지표

| 지표 | 목표 |
|------|------|
