# PRD ONE-PAGER — MOODEX v0.1

**작성일**: 2026-03-23
**스코프**: 1주 MVP

---

## 1. 문제 정의

한국 개인 투자자는 시장이 극단적 공포나 탐욕 구간에 있을 때 **무엇을 해야 할지 모른다**.
CNN Fear & Greed 같은 도구는 숫자를 보여주지만 그 숫자의 의미, 역사적 맥락, 자산별 함의, 실전 활용법은 알려주지 않는다.
결과적으로 투자자는 숫자를 보고도 "그래서 어쩌라고?"라는 상태에 머문다.

---

## 2. 제품 비전

**지수를 보는 것을 넘어, 지수를 이해하고 활용하는 도구.**

MOODEX는 매일 시장심리 점수를 계산하고,
그 점수가 **역사적으로 어디에 위치하는지**, **자산군에 어떤 함의를 갖는지**, **투자자가 어떻게 반응하면 합리적인지**를 명확한 언어로 제공한다.

---

## 3. 타겟 사용자

| 사용자 유형 | 설명 |
|------------|------|
| **Primary** | 한국 개인 투자자, 주식+코인 병행, 뉴스는 보지만 체계적 분석 툴은 없음 |
| **Secondary** | 재테크 콘텐츠 크리에이터 (스크린샷/레퍼런스 용도) |
| **Not target** | 기관 투자자, 알고 트레이더 (그들은 이미 다른 도구가 있음) |

---

## 4. 핵심 가치 제안 (3줄)

1. **오늘의 심리**: 숫자 + "왜 이 구간인가"를 한 문장으로
2. **역사 속 내 위치**: 지금 점수가 과거 위기/버블과 비교했을 때 어디인지
3. **내가 할 일**: 이 심리 구간에서 일반적으로 합리적인 투자자 행동 프레임

---

## 5. 데이터 소스 결정

| 소스 | 역할 | API |
|------|------|-----|
| alternative.me Crypto F&G | 코인 시장심리 점수 (주지수) | 무료, 일별 |
| Yahoo Finance / yfinance | VIX (주식시장 공포도) | 무료, 실시간 |
| FRED API | 미국채 스프레드, 신용스프레드 (보조) | 무료, 일별 |
| KRX (선택) | VKOSPI 국내 변동성 | 무료이나 스크래핑 필요 → Phase 2 |

**MVP 결정**: 코인 F&G (primary) + VIX (secondary). 두 지수를 가중평균한 **MOODEX Score (0–100)**를 자체 지수로 표시. CNN 복제 아님.

---

## 6. MOODEX Score 계산식 (MVP 간소화)

```
MOODEX Score = (Crypto F&G × 0.5) + ((100 - VIX_normalized) × 0.5)

VIX_normalized = clamp((VIX - 10) / (80 - 10) × 100, 0, 100)
```

레짐 레이블:
- 0–24: 극단적 공포 (Extreme Fear)
- 25–44: 공포 (Fear)
- 45–55: 중립 (Neutral)
- 56–74: 탐욕 (Greed)
- 75–100: 극단적 탐욕 (Extreme Greed)
